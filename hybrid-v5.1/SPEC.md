# V5.1 spec

V5.1 preserves the V3 sequence through the ten-minute modeled checkpoint.
Country can select a language profile. Venue and address affect later
output. With no extra context, the stream matches V5.

The test suite checks early sequence stability, input handling, baseline
validation, and differences in later output. The historical comparison used
network names only, so the data could only confirm parity with V5.

The report archive contains aggregate results and its review log. The
builder checks that local Markdown links resolve inside the archive.
