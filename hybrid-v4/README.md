# V4.1 experiment

V4.1 adds staged scheduling and country-based language profiles to V3.
It trailed V3 at all eight checkpoints in the historical comparison.
At the two-hour checkpoint, V4.1 had 278 matches and V3 had 286.

The [wordlist manifest](wordlists/manifest.json) records the source and
checksums for the language data. FrequencyWords uses OpenSubtitles 2018
data and is available under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

- [Spec](SPEC.md) records the experiment design.
- [Review](REVIEW.md) summarizes the fixes before the comparison.
- [Release manifest](release-manifest.json) records the original release.
