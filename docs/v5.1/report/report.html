V5.1 comparison

At two hours, V5.1 matched 325 records and V3 matched 286. V5.1 gained 40 matches, lost one, and used 15.47% fewer attempts per match.

The study used 852 previously seen records across 814 network names. Both versions used the same budgets, modeled at 235,000 checks per second.

The study verified the V3 baseline before reusing it. The records contained network names only.
