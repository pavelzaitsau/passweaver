# V5.1 decisions

V5.1 remains the latest reviewed hybrid. The follow-up study left the
main profile as it was.

## Why the profile stayed

A separate control case found no match. The follow-up study identified
a gap in the existing patterns, but that gap added no direct matches on
the 852 historical records.

The study used saved match positions to estimate the effect of adding a
new block within the same total budget. Both estimates lost matches.

| Scenario | 30 min | 1 h | 2 h |
| --- | --- | --- | --- |
| Original V5 | 294 | 308 | 325 |
| Smaller block | 288 | 307 | 324 |
| Full block | 281 | 302 | 323 |

The last two rows are estimates from saved results. A separate holdout set
would be needed to test any new profile. See the [report](report/RESULTS.md)
for the measured comparison.
