# V5.1 guide

V5.1 is the latest hybrid in Passweaver. It fixes context handling and
report packaging. See the [V5.1 source guide](../../hybrid-v5.1/README.md).

The historical comparison repeated the V5 results on 852 reused records.
V5.1 matched 325 records at the two-hour checkpoint. V3 matched 286.
The data contained network names only, so the comparison could not
measure the effect of country, venue, or address.
